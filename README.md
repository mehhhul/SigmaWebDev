# SigmaWebDev

A collection of mini-projects built while learning web development through the **Sigma Web Development Course** by [CodeWithHarry](https://www.youtube.com/@CodeWithHarry) on YouTube.

## About
This repo is a learning log — each folder is a small, self-contained project built to practice a specific concept (HTML basics, CSS layouts, positioning, responsiveness, etc.) as I go through the course.

Each project folder has its own `index.html`, `style.css` (and `script.js` where relevant), along with a short README explaining what it covers.

## Tech Stack
- HTML5
- CSS3
- JavaScript (as the course progresses)

## Goal
Build a strong foundation in web fundamentals before moving to frameworks — tracking progress project by project.
