# Nature Card

A simple responsive card component built with HTML and CSS, displaying an image, tags, title, and description with a "Read More" button.

## Features
- Responsive card layout (max-width 400px, scales on smaller screens)
- Image with rounded corners
- Category tags (e.g. "Nature", "Mountains")
- Title and description section
- "Read More" button with hover effect, centered at the bottom of the card

## Tech Used
- HTML5
- CSS3 (Flexbox-free — uses `position: absolute` for button placement)

## Preview
The card displays a photo of the Shivalik Range (foothills of the Himalayas) with a short description.

## How to Run
1. Clone this repo
2. Open `index.html` in your browser

## Notes
This is a practice exercise focused on:
- Card UI layout
- Positioning (`absolute` + `transform: translateX(-50%)` for centering)
- Basic hover transitions
