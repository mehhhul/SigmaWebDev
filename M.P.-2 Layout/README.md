# Sigma Web Dev — Layout Practice

A small HTML/CSS exercise practicing page layout using CSS positioning and box display properties, without any layout framework.

## What I practiced

- **Positioning**: `sticky` (header, logo), `absolute` (footer), `relative` (body container)
- **Display types**: `inline-block` for placing boxes side by side
- **Box model**: margin, padding, border-radius, centering a box with `margin: auto`
- **Fixed-size layout**: built at a fixed 500x600 canvas size (not yet responsive — next step)

## Structure

- `.head` — sticky top bar
- `.main` — content section holding two side-by-side boxes (`.orange`, `.blue`)
- `.box` — centered rounded text card
- `.footer` — bar pinned to the bottom
- `.logo` — small sticky logo in the corner

## Files

- `index.html` — markup
- `style.css` — styles

## Notes

This is a practice layout, not a production page.
